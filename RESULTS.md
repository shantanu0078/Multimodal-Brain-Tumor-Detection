# Results

This document summarizes the evaluation outputs generated by the proposed multimodal brain tumor detection framework.

---

## Evaluation Protocol

The proposed framework is evaluated using **5-fold cross-validation** to provide a robust assessment of model performance. Each dataset described in **DATASET.md** is trained and evaluated **independently**, and the reported performance is obtained by averaging the results across all folds.

---

## Evaluation Metrics

The framework reports the following performance metrics:

* Accuracy
* Precision
* Recall
* F1-Score
* Area Under the ROC Curve (AUC)
* Matthews Correlation Coefficient (MCC)

---

## Explainable AI

To improve model interpretability, the framework generates multiple Explainable AI (XAI) visualizations, including:

* Grad-CAM++ heatmaps
* Prototype attention visualization
* UMAP feature embeddings
* Prototype similarity analysis

These visualizations provide additional insight into the learned feature representations and support the interpretation of the model's predictions.

---

## Reproducibility

The complete evaluation pipeline is available in:

```text
notebooks/Multimodal_Brain_Tumor_Detection.ipynb
```

Executing the notebook reproduces the training, evaluation, and visualization procedures described in this repository.
